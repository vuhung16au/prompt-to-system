---
id: prompt-injection
title: "Prompt Injection"
summary: "A vulnerability where an attacker manipulates a model's output by injecting malicious instructions into user input."
aliases: ["jailbreaking"]
---
Prompt injection is the AI equivalent of SQL injection. Attackers try to override the system prompt and take control of the model. Preventing it requires input sanitization, clear delimiters, and strong system prompt guardrails.
