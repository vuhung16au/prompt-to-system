---
id: system-prompt
title: "System Prompt"
summary: "A special instruction set given to an LLM at the beginning of a session to define its overarching behavior and constraints."
aliases: ["system message", "developer message"]
---
The system prompt acts as the foundational set of rules for the model. It defines the persona, establishes guardrails, and provides global context that the model should adhere to throughout the conversation.
