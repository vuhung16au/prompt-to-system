---
id: tool-permissions
title: "Tool Permissions"
summary: "The set of actions an agent is authorized to perform via its available tools."
---
In agentic systems, the principle of least privilege should be applied to tool permissions. An agent should only be granted access to the specific tools (e.g., read-only file access vs. write access) necessary for its current task to minimize the blast radius of errors or prompt injections.
