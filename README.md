# Applied LLM Patterns

**Applied LLM Patterns** is a concise, open-source educational knowledge base for intermediate and advanced LLM users. 

This project aims to help you move beyond basic chat prompts into designing reliable, repeatable systems and workflows. It provides a curated library of practical examples and a structured curriculum to elevate how you work with Large Language Models.

## 🎯 Target Audience

This repository and website are designed for professionals who already know the basics of prompting and are looking for more reliable workflows. This includes:
- **Software Engineers & IT Practitioners:** Writing, debugging, testing, and automating.
- **Researchers & Analysts:** Data extraction, synthesis, and literature review.
- **Sales & Marketing Professionals:** Campaign planning, copywriting, and audience analysis.
- **Knowledge Workers:** Anyone using LLMs for high-leverage productivity and decision-making.

## 📚 Curriculum Structure

The learning path, "From Prompts to Systems", is broken down into a progressively broader five-layer model:

1. **Prompt Engineering:** *What should the model do in this interaction?* (Mastering single-turn instructions and formatting).
2. **Context Engineering:** *What should the model know and see?* (Retrieval-Augmented Generation, few-shot examples, and context window management).
3. **Workflow Engineering:** *What steps produce the result?* (Chaining multiple steps, playbooks, and human-guided sequences).
4. **Harness Engineering:** *What tools, constraints, and feedback support the agent?* (Tool calling, sandboxing, and executing code safely).
5. **Loop Engineering:** *How does repeated work converge, stop, recover, or escalate?* (Autonomous agents, self-correction, and termination rules).

*(Cross-cutting themes like Evaluation, Reliability, and Safety are applied across all five layers).*

## 📖 How to Use This Project as Learning Material

- **Read the Lessons:** Navigate to the `/learn` section of the deployed site to read concise, 3-7 minute lessons covering each of the five engineering layers.
- **Browse the Examples:** We firmly believe in *example-driven learning*. Every lesson links to concrete examples. You can browse the `/examples` directory or the Examples page on the site to find practical use cases organized by domain (Software Engineering, Writing, Marketing, etc.).
- **Copy and Adapt:** All examples include their raw prompts, required inputs, and evaluation rubrics. You are encouraged to copy these patterns and adapt them to your specific use cases.
- **Contribute:** If you have developed a reliable LLM pattern, check out [CONTRIBUTING.md](./CONTRIBUTING.md) to see our taxonomy, templates, and how you can add to the library!
